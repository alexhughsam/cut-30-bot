# Autopsy Intake — what the creator sends after posting

Copy this list to the creator when they say a video is up. Everything here is raw
material only they have. Missing items limit the diagnosis — say WHICH levers become
unassessable, don't silently guess.

## Required
1. **The video itself** (file or link). Transcript alone blocks: hook visual grading,
   pacing/edit judgment, first-frame muted-autoplay check, set/recognition read. Say so
   if that's all we get.
2. **The numbers** (as of a stated timestamp — numbers without an age are noise):
   - Views
   - Watch time / retention: average % watched, and the drop-off shape if the platform
     shows it (X Analytics, TikTok retention graph). Named timestamps of the big drops.
   - Likes, replies, reposts, quote-posts, bookmarks/saves
   - Profile visits / follows from the post, if visible
3. **The comments** — paste them raw, including the dunks. Reply patterns are evidence
   (what line do people quote? what do they correct? what do they ask?).
4. **Distribution source, if visible:** did views come from the feed, from search, from
   the QT/reply anchor, or from one bigger account engaging?

## Context (from SWIPE_FILE.md, confirm with creator)
5. **The open experiment** — the single change prescribed last time. Was it actually
   in this video? (First thing the autopsy checks.)
6. **Baseline** — typical views / retention / drop point across prior videos. For the
   first ~3 videos there is no baseline: read against the videos' own shape + platform
   norms, and label confidence accordingly.

## Rules that bind the autopsy (from PROMPT.md — do not skip)
- Form your own read but show it to NO ONE. Run the blind review first
  (templates/BLIND_AUTOPSY_PROMPT.md); if the blind reviewer ties a different lever
  harder to the data, its call stands.
- One biggest lever, pinned to evidence (named timestamp / watchable failure / comment
  pattern). If the data can't separate two levers, deliver both and say so.
- An autopsy may name ANY lever the data supports — topic, audience fit, format,
  timing, distribution — don't force a hook-and-retention frame.
- End with exactly ONE change to test next video. Log it as the new open experiment.
